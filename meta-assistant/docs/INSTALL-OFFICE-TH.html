📦 ติดตั้งปุ่ม "ส่งรูปสินค้าทั้งหมด"

สำหรับ Meta Business Suite · ทำครั้งเดียว ประมาณ 5 นาที · เวอร์ชัน 1.1.0
ปุ่มนี้ทำอะไร
กดครั้งเดียว = ส่งรูปสินค้าที่ มีของพร้อมส่ง ทั้งหมดให้ลูกค้าในแชท
เฟซบุ๊กส่งได้ครั้งละ 10 รูป โปรแกรมจะแบ่งส่งให้เองจนครบ
สินค้าที่กด "หมด" ในแอป KP จะ ไม่ถูกส่ง โดยอัตโนมัติ — ไม่ต้องเก็บโฟลเดอร์รูปเองอีกต่อไป

ขั้นตอนติดตั้ง

  1. ดาวน์โหลดไฟล์ KP-Sortiment-Extension-v1.1.0.zip ลงเครื่อง
  2. คลิกขวาที่ไฟล์ → แตกไฟล์ทั้งหมด (Extract All / Alle extrahieren)
  3. ช่องปลายทาง พิมพ์ C:\KP\extension แล้วกดแตกไฟล์
  4. เปิดโฟลเดอร์ C:\KP\extension ต้องเห็นไฟล์ manifest.json และโฟลเดอร์ background, content
    ถ้าเห็นโฟลเดอร์ชื่อ extension ซ้อนอยู่ข้างใน ให้ย้ายไฟล์ข้างในขึ้นมาหนึ่งชั้น
  5. เปิด Chrome พิมพ์ chrome://extensions ในช่องที่อยู่ แล้วกด Enter
  6. เปิดสวิตช์ โหมดนักพัฒนา มุมขวาบน (Developer mode / Entwicklermodus)
  7. กดปุ่ม โหลดส่วนขยายที่แตกไฟล์แล้ว มุมซ้ายบน (Load unpacked / Entpackte Erweiterung laden)
  8. เลือกโฟลเดอร์ C:\KP\extension แล้วกดเลือกโฟลเดอร์
  9. จะเห็นการ์ด KP Sortiment senden 1.1.0 = ติดตั้งเสร็จแล้ว
ห้ามลบหรือย้ายโฟลเดอร์ C:\KP\extension — Chrome เปิดไฟล์จากที่นี่ทุกครั้ง
และ อย่าแตกไฟล์ไว้ใน Google Drive (ไดรฟ์ G:) ให้แตกลงเครื่องตามที่อยู่ข้างบนเท่านั้น

ทดสอบ 1 ครั้งก่อนใช้กับลูกค้า

  1. เปิด business.facebook.com → กล่องข้อความ → เปิด แชทของตัวเอง (อย่าเพิ่งทดสอบกับลูกค้า)
  2. ด้านขวาจะมีกล่อง KP Sortiment พร้อมรูปสินค้าเล็ก ๆ
  3. กด ไม่เลือก แล้วคลิกเลือกสินค้า 1 ตัว
  4. กดปุ่ม 📦 แล้วกด ตกลง ในกล่องยืนยัน
  5. ถ้ารูปนั้นส่งออกไปในแชท = เครื่องนี้พร้อมใช้งานแล้ว

วิธีใช้ประจำวัน

  1. ลูกค้าถามว่ามีรุ่นไหนบ้าง → เปิดแชทของลูกค้า → กดปุ่ม 📦 → กดตกลง
  2. รอประมาณ 1 นาที ระหว่างส่งอย่าเปลี่ยนแชท และอย่าปิดหน้าต่าง
  3. อยากส่งเฉพาะบางรุ่น: คลิกที่รูปเพื่อเอาออก (รูปจะกลายเป็นสีเทา) คลิกอีกครั้งเพื่อเลือกกลับ
    ปุ่ม ทั้งหมด = เลือกทุกตัว · ปุ่ม ไม่เลือก = เอาออกทุกตัว
  4. ที่ปุ่มจะบอกเสมอว่าจะส่งกี่รูป และส่งกี่ข้อความ
  5. ส่งเสร็จแล้ว ระบบจะเลือกสินค้าทั้งหมดกลับให้เอง สำหรับลูกค้าคนต่อไป

อาการทำอย่างไร
ไม่เห็นปุ่ม "โหลดส่วนขยายที่แตกไฟล์แล้ว"ยังไม่ได้เปิดโหมดนักพัฒนา (สวิตช์มุมขวาบน)
ไม่เห็นกล่อง KP Sortimentกด F5 รีเฟรชหน้า business.facebook.com หนึ่งครั้ง
⚠ ไม่พบช่องพิมพ์ — เปิดแชทไว้หรือยัง?ยังไม่ได้เปิดแชท ให้คลิกแชทของลูกค้าก่อน
⚠ โหลดรายการสินค้าไม่ได้แจ้ง André
⚠ ใส่รูปไม่สำเร็จ / ส่งไม่ออกถ่ายรูปหน้าจอส่งให้ André
⚠ ยังไม่มีรูป: KP0xxสินค้ารุ่นนั้นยังไม่มีรูปในระบบ แจ้ง André

เวลามีเวอร์ชันใหม่

  1. André จะส่งไฟล์ ZIP ใหม่มาให้
  2. แตกไฟล์ทับที่เดิม C:\KP\extension (กดแทนที่ไฟล์เดิมทั้งหมด)
  3. เปิด chrome://extensions แล้วกดปุ่ม ⟳ ที่การ์ด KP Sortiment
  4. กด F5 ที่หน้า business.facebook.com
