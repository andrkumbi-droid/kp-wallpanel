ปุ่มนี้ทำอะไร
กดครั้งเดียว = ส่งรูปสินค้าที่ มีของพร้อมส่ง ทั้งหมดให้ลูกค้าในแชท
เฟซบุ๊กส่งได้ครั้งละ 10 รูป โปรแกรมจะแบ่งส่งให้เองจนครบ
สินค้าที่กด "หมด" ในแอป KP จะ ไม่ถูกส่ง โดยอัตโนมัติ — ไม่ต้องเก็บโฟลเดอร์รูปเองอีกต่อไป
ใหม่ในเวอร์ชัน 1.2.0: เลือกส่งเฉพาะกลุ่มได้ เช่น เฉพาะ PVC หรือเฉพาะ 3 ลอนลึก

ติดตั้ง (ทำครั้งเดียว)

  1. บันทึกไฟล์ KP-Sortiment-Set.zip ที่ André ส่งให้ ลงในเครื่อง
  2. คลิกขวาที่ไฟล์ → แตกไฟล์ทั้งหมด (Extract All) จะได้ไฟล์ KP-Update.bat กับคู่มือนี้
  3. ลากไฟล์ KP-Update.bat ไปวางที่ หน้าเดสก์ท็อป (เก็บไว้ตลอด ใช้ทุกครั้งที่มีเวอร์ชันใหม่)
  4. ดับเบิลคลิก ที่ KP-Update.bat
    ถ้าขึ้นหน้าจอสีน้ำเงิน "Windows ป้องกันคอมพิวเตอร์ของคุณ" ให้กด ข้อมูลเพิ่มเติม → เรียกใช้ต่อไป (ไฟล์นี้มาจาก André ไม่ใช่ไวรัส)
  5. รอสักครู่ จะขึ้นบรรทัด ok 7 บรรทัด และคำว่า fertig / เสร็จแล้ว: v1.2.0 แล้วกดปุ่มใดก็ได้เพื่อปิดหน้าต่าง
    ไฟล์ทั้งหมดจะลงที่ C:\KP\extension ให้เอง ไม่ต้องแตกไฟล์เอง
  6. เปิด Chrome พิมพ์ chrome://extensions ในช่องที่อยู่ แล้วกด Enter
  7. เปิดสวิตช์ โหมดนักพัฒนา มุมขวาบน (Developer mode)
  8. กดปุ่ม โหลดส่วนขยายที่แตกไฟล์แล้ว มุมซ้ายบน (Load unpacked)
  9. เลือกโฟลเดอร์ C:\KP\extension แล้วกดเลือกโฟลเดอร์
  10. จะเห็นการ์ด KP Sortiment senden 1.2.0 = ติดตั้งเสร็จแล้ว
  11. เปิด business.facebook.com แล้วกด F5 หนึ่งครั้ง กล่อง KP Sortiment จึงจะขึ้น (หน้าที่เปิดค้างไว้ก่อนติดตั้ง จะยังไม่มีปุ่ม)
ห้ามลบหรือย้ายโฟลเดอร์ C:\KP\extension — Chrome เปิดไฟล์จากที่นี่ทุกครั้ง
และ อย่าเก็บไว้ใน Google Drive ให้อยู่ในเครื่องตามที่อยู่ข้างบนเท่านั้น

ทดสอบ 1 ครั้งก่อนใช้กับลูกค้า

  1. เปิด business.facebook.com → กล่องข้อความ → เปิด แชทของตัวเอง (อย่าเพิ่งทดสอบกับลูกค้า)
  2. ด้านขวาจะมีกล่อง KP Sortiment พร้อมรูปสินค้าเล็ก ๆ
  3. กด ไม่เลือก แล้วคลิกเลือกสินค้า 1 ตัว
  4. กดปุ่ม 📦 แล้วกด ตกลง ในกล่องยืนยัน
  5. ถ้ารูปนั้นส่งออกไปในแชท = เครื่องนี้พร้อมใช้งานแล้ว

วิธีใช้ประจำวัน

  1. ลูกค้าถามว่ามีรุ่นไหนบ้าง → เปิดแชทของลูกค้า → กดปุ่ม 📦 → กดตกลง
  2. รอประมาณ 1 นาที ระหว่างส่งอย่าเปลี่ยนแชท และอย่าปิดหน้าต่าง
  3. ที่ปุ่มจะบอกเสมอว่าจะส่งกี่รูป และส่งกี่ข้อความ
  4. ส่งเสร็จแล้ว ระบบจะเลือกสินค้าทั้งหมดกลับให้เอง สำหรับลูกค้าคนต่อไป

เลือกส่งเฉพาะกลุ่ม (ใหม่)

เหนือรูปสินค้า มีปุ่มกลุ่มเรียงอยู่ กดปุ่มเดียว = เลือกเฉพาะกลุ่มนั้น

ทั้งหมด · 🪵 WPC · 🔲 PVC · 3 ลอนกลาง · 3 ลอนลึก · 4 ลอนลึก · 5 ลอนตื้น · 2 ลอนเรียบ · หน้าเรียบ · หน้าเรียบ 40cm · …

ตัวเลขหลังชื่อ = มีกี่สีที่พร้อมส่งในกลุ่มนั้น
  1. ลูกค้าถามเฉพาะ PVC → กด 🔲 PVC → กดปุ่ม 📦 (ส่งแค่ PVC ไม่กี่รูป เร็วกว่ามาก)
  2. ลูกค้าถามลอนลึก 3 ร่อง → กด 3 ลอนลึก → กด 📦
  3. หลังกดปุ่มกลุ่มแล้ว ยังคลิกรูปเพิ่ม/เอาออกได้อีก (รูปสีเทา = ไม่ส่ง)
  4. กลับมาส่งทุกอย่าง: กด ทั้งหมด
  5. มีสินค้ารุ่นใหม่หรือกลุ่มลอนใหม่ในแอป KP → ปุ่มขึ้นเองอัตโนมัติ ไม่ต้องติดตั้งอะไรเพิ่ม

เวลามีเวอร์ชันใหม่

  1. André บอกว่ามีของใหม่ → ดับเบิลคลิก KP-Update.bat ที่หน้าเดสก์ท็อป
  2. รอจนขึ้น เสร็จแล้ว แล้วปิดหน้าต่าง
  3. ไปที่หน้า business.facebook.com แล้ว กด F5 — เท่านี้จบ
ไม่ต้องรอไฟล์ ZIP ใหม่ ไม่ต้องแตกไฟล์ ไม่ต้องกด ⟳ ใน chrome://extensions
(ถ้า André บอกว่าครั้งนี้ต้องกด ⟳ ด้วย ให้กดที่การ์ด KP Sortiment หนึ่งครั้ง)

สินค้า รูป ราคา ของหมด และกลุ่มลอน ไม่ต้องอัปเดตเลย — มาจากแอป KP เอง แค่กด F5 ก็ได้ของใหม่
